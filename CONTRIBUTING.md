## Clean-room rule

Contributions must contain **no Angstrong/Yahboom vendor source or binaries**,
and no code derived from disassembling them. Work only from observed device
behaviour (USB descriptors, captured frames, the vendor driver's *published*
output) and the specification in `docs/`. Never commit raw captures: they are
images of real rooms.
